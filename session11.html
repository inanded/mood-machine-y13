Three Piles of Faces

Today you'll choose settings by trying lots of them and keeping the best. That needs a third pile of faces.

Pile How many Use it to
Training 10,000 change the weights
Validation 2,000 compare settings and choose the best
Test 3,000 report the final score, once, at the very end

Why not compare settings on the test faces? If you try 20 settings and keep the one with the best test score, you have chosen the settings that suit those 3,000 faces. Some of that score is luck, and the test faces have stopped being new. Your final score would look better than the Mood Machine is. The validation faces take the knocks instead, and the test faces stay untouched until the end.

Key idea

Training faces teach. Validation faces choose. Test faces judge, once.

Overfitting in Action

In your notebook

Run section 2. It trains a Mood Machine on only 500 faces, for 20 epochs, and prints the training and validation scores every 4 epochs.

epoch 4   training 53.6 %   validation 38.0 %
epoch 8   training 70.8 %   validation 50.8 %
epoch 12  training 80.4 %   validation 59.5 %
epoch 16  training 84.0 %   validation 62.4 %
epoch 20  training 85.8 %   validation 63.5 %

The gap keeps growing. With only 500 faces to learn from, seen 20 times each, the Mood Machine starts to memorise those faces: the exact colours, sizes and tilts of each one. That helps it on the training faces and does nothing for new ones. This is overfitting.

It's like the student who memorised last year's exam paper: great on that paper, worse on a new one. Training on 10,000 faces makes overfitting much harder, because there are too many to memorise.

The Challenge

train_mood_machine trains a new Mood Machine with the settings you choose and prints the training and validation scores.

Setting Starts at What it changes
hidden 256 how many neurons in the first hidden layer
learning_rate 0.001 how big each step downhill is
epochs 3 how many times it goes through the training faces
training_faces 10000 how many training faces it learns from
seed 1 the random starting weights

The rules:

  1. Change one setting at a time, so you know what made the difference.
  2. Compare runs by their validation score.
  3. Record every run in a table, including the ones that made it worse.
  4. Each run takes about a minute, so predict the result before you run.

There are two routes. Route A uses train_mood_machine(). Route B is harder: you write the whole experiment yourself (see the last section). Both routes finish by marking the test faces once.

1000 training faces:   training 41.0 %   validation 37.9 %

10000 training faces:  training 83.3 %   validation 81.2 %
Stuck for ideas?
  • Does training for more epochs keep helping, or does it stop?
  • Is a bigger hidden layer always better? Is it slower?
  • Can you find a learning rate that's too big for the Mood Machine, like 0.8 was for the bounce line?
  • How much does the score change if you only change the seed? If two settings differ by less than that, you can't say one is better.

Mark It Once

When you have chosen your best settings, put them in the section 4 cell and run it. It trains a Mood Machine with those settings and marks the 3,000 test faces. That's your final score. Don't go back and tune again: if you do, the test faces are no longer new.

In our run, six epochs scored 85.8% on the validation faces and 85.1% on the test faces. The two are close, which is what you'd expect when the test faces were kept out of the choosing.

Harder: Build Your Own Experiment

Route B replaces train_mood_machine() with code you write yourself, in section 5. Follow the comments. The cheat sheet has every pattern you need.

Your experiment should also keep the best epoch. After every epoch, check the validation score. If it's the best so far, save the model. Then, if later epochs get worse, you still have the best one. This is called early stopping, and in our run it mattered: the score went up, dipped, then rose again.

epoch 1  validation 70.6 %
epoch 2  validation 81.2 %
epoch 3  validation 79.0 %
epoch 4  validation 85.2 %
epoch 5  validation 86.0 %

When you've finished, run the CHECK cell. It loads your saved model and marks it on the validation faces. Then mark the test faces once, as in Route A.

Hint for steps 1 and 2: the loader, model, loss and optimiser

You need a DataLoader of train_part with batch_size=64 and shuffle=True, then a MoodNet, a loss function and an optimiser, as in Session 8.

my_loader = DataLoader(train_part, batch_size=64, shuffle=True)
my_net = MoodNet(hidden=256).to(device)
my_opt = torch.optim.Adam(my_net.parameters(), lr=0.001)
my_loss_fn = nn.CrossEntropyLoss()
best_val = 0
Hint for step 4: one epoch at a time

You need two loops, one inside the other: for epoch in range(1, 6): on the outside, and for faces, moods in my_loader: inside it. The inside loop is the five-step training loop. After it, still inside the epoch loop, work out the validation score.

Show the code 
for epoch in range(1, 6):
    my_net.train()
    for faces, moods in my_loader:
        faces, moods = faces.to(device), moods.to(device)
        loss = my_loss_fn(my_net(faces), moods)
        my_opt.zero_grad()
        loss.backward()
        my_opt.step()
    val = check_accuracy(my_net, val_loader)
    print("epoch", epoch, " validation", round(val, 1), "%")
Hint for step 4d: keep the best epoch

Use an if to compare val with best_val. This goes at the end of the epoch loop, at the same indent as val = ....

Show the code 
    if val > best_val:
        best_val = val
        torch.save(my_net.state_dict(), "my_best.pth")

Check Your Understanding

Check your understanding

1. A system that spots plant diseases from photos scores 96% on its test set. When farmers use it with their own photos, it does much worse. Suggest two reasons why. 2 points

2. Explain the difference between machine learning and deep learning. 2 points

3. Explain why a model's settings are chosen using a validation set rather than the test set. 2 points

4. A heating system learns to save energy. It changes the settings and gets a score based on energy used and how comfortable people say they are. Which kind of learning is this? Explain why it suits the task. 3 points

What a full answer includes

1 Any 2 of:

  • the farmers' photos are different from the training photos (lighting, angle, background, quality)
  • the training photos didn't cover the conditions or plants found on real farms
  • the model has overfitted to details of its training photos
  • the test photos came from the same place as the training photos, so the test didn't show the problem

2 Machine learning: systems that learn from data instead of following rules a person wrote. Deep learning: a kind of machine learning that uses neural networks with many hidden layers.

3 If settings are chosen because they score well on the test set, the settings have been tuned to those particular examples, so the test set is no longer unseen data. The final test score would then overestimate how well the model works on new data. Choosing on a validation set keeps the test set as a fair, unseen check.

4 Reinforcement learning: the system takes actions and gets a reward (the score), not right answers. It suits the task because nobody knows the best setting for every situation, so it has to learn by trying, and it can keep adjusting as the weather and the building's use change.
