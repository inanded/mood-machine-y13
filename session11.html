Overfitting in Action 0-12 min

Every run today prints two scores:

  • Training accuracy: on the faces it learned from.
  • Test accuracy: on the 3,000 faces it has never seen.

In your notebook

Run section 1. It trains a Mood Machine on only 500 faces, for 20 epochs, and prints both scores every 4 epochs.

epoch 4   training 53.6 %   test 40.2 %
epoch 8   training 70.8 %   test 54.3 %
epoch 12  training 80.4 %   test 61.8 %
epoch 16  training 84.0 %   test 64.3 %
epoch 20  training 85.8 %   test 65.0 %

The gap keeps growing. With only 500 faces to learn from, seen 20 times each, the Mood Machine starts to memorise those faces: the exact colours, sizes and tilts of each one. That helps it on the training faces and does nothing for new ones. This is overfitting.

It's like the student who memorised last year's exam paper: great on that paper, worse on a new one. Training on 12,000 faces makes overfitting much harder, because there are too many to memorise.

Key idea

When the training accuracy climbs well above the test accuracy, the model is overfitting. Only the test accuracy tells you how well it works on new data, so only the test accuracy counts in the challenge.

The Challenge 12-17 min

train_mood_machine trains a new Mood Machine with the settings you choose and prints both scores. Everyone is marked on the same 3,000 test faces, so the results are fair to compare.

Setting Starts at What it changes
hidden 256 how many neurons in the first hidden layer
learning_rate 0.001 how big each step downhill is
epochs 3 how many times it goes through the training faces
training_faces 12000 how many training faces it learns from
seed 1 the random starting weights

The rules:

  1. Change one setting at a time, so you know what made the difference.
  2. Record every run in a table, including the ones that made it worse.
  3. Each run takes about a minute, so predict the result before you run.

Run Your Experiments 17-45 min

In your notebook

Run section 2 to get the starting score. Then use the YOUR TURN cell for your experiments.

As an example, here's what changing the number of training faces did in our run:

1000 training faces:   training 41.0 %   test 38.7 %
3000 training faces:   training 76.8 %   test 74.0 %
12000 training faces:  training 83.7 %   test 82.2 %
Stuck for ideas?
  • Does training for more epochs keep helping, or does it stop?
  • Is a bigger hidden layer always better? Is it slower?
  • Can you find a learning rate that's too big for the Mood Machine, like 0.8 was for the bounce line?
  • How much does the score change if you only change the seed? If two settings differ by less than that, you can't say one is better.

Check Your Understanding 52-60 min

Check your understanding

1. A system that spots plant diseases from photos scores 96% on its test set. When farmers use it with their own photos, it does much worse. Suggest two reasons why. 2 points

2. Explain the difference between machine learning and deep learning. 2 points

3. A heating system learns to save energy. It changes the settings and gets a score based on energy used and how comfortable people say they are. Which kind of learning is this? Explain why it suits the task. 3 points

What a full answer includes

1 Any 2 of:

  • the farmers' photos are different from the training photos (lighting, angle, background, quality)
  • the training photos didn't cover the conditions or plants found on real farms
  • the model has overfitted to details of its training photos
  • the test photos came from the same place as the training photos, so the test didn't show the problem

2 Machine learning: systems that learn from data instead of following rules a person wrote. Deep learning: a kind of machine learning that uses neural networks with many hidden layers.

3 Reinforcement learning: the system takes actions and gets a reward (the score), not right answers. It suits the task because nobody knows the best setting for every situation, so it has to learn by trying, and it can keep adjusting as the weather and the building's use change.
