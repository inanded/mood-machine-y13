Scoring a Guess: Cross-Entropy Loss

For the bounce line, the loss was the mean squared error. For picking one mood out of ten, we use cross-entropy loss. It works in two steps:

  1. Softmax turns the 10 scores into 10 chances that add up to 100% (you met this in Session 7).
  2. The loss looks only at the chance given to the right mood, and works out −log(chance).

You don't need to know logarithms in detail. What matters is the shape:

Chance given to the right mood Loss
99% 0.01
90% 0.11
50% 0.69
10% 2.30
1% 4.61
  • Sure and right: the loss is close to 0.
  • Unsure: the loss is middling.
  • Sure and wrong (it gave the right mood a tiny chance): the loss is huge.

So training is pushed hardest to fix the guesses where the network was confidently wrong. Before training, every mood gets about a 10% chance, so the loss starts near 2.3.

Changing the Weights: The Optimiser

The optimiser is the part of the code that changes the weights, using the gradients that back propagation finds. It is the "step downhill" from Session 5.

Plain gradient descent (called SGD in PyTorch) does exactly what you did with the bounce line: every weight moves by learning rate × its gradient, every step.

Adam is the optimiser we use. It's gradient descent with two improvements:

  1. It builds up speed. It keeps a running average of each weight's recent gradients. If a weight keeps being pushed the same way, it keeps moving that way, like a ball rolling downhill. Jumpy gradients from single batches cancel out, so the path is smoother.
  2. Each weight gets its own step size. Weights whose gradients are usually large take smaller steps. Weights whose gradients are usually tiny take bigger steps. So all 820,874 weights make progress, not just the ones with big gradients.
loss_fn = nn.CrossEntropyLoss()
optimiser = torch.optim.Adam(model.parameters(), lr=0.001)

model.parameters() hands the optimiser all 820,874 weights and biases. lr=0.001 is the learning rate.

The Training Loop

For every batch of 64 faces, the loop does five steps:

guesses = model(faces)            # 1. make guesses
loss = loss_fn(guesses, moods)    # 2. how wrong were they?
optimiser.zero_grad()             # 3. wipe old gradients
loss.backward()                   # 4. find new gradients (back propagation)
optimiser.step()                  # 5. nudge the weights
  1. Forward pass. The 64 faces go through MoodNet. Out come 64 sets of 10 scores.
  2. Loss. Cross-entropy compares the scores with the right moods and averages over the batch.
  3. Wipe the old gradients. Otherwise they pile up, as you saw in Session 5.
  4. Back propagation. loss.backward() works backwards from the loss through every layer and finds the gradient for every weight and bias. In Session 9 you'll do this by hand.
  5. Update. Adam moves every weight a small step downhill.

The marking function, check_accuracy, runs the test faces through and counts how many guesses are right. It never changes a weight, so it has no backward() and no step().

Think

  1. Most of the improvement happens in the first epoch. Why?
  2. The loss shown is for the last batch only. Why does it jump around more than the accuracy?
Answers
  1. At the start the network is very wrong, so the loss and the gradients are big, and each step makes a big difference. Near the bottom of the valley the slope is gentler.
  2. One batch is only 64 faces, and some batches are harder than others. The accuracy is measured over all 3,000 test faces, so it's much steadier.

What a full answer includes

1 Any 4 of:

  • a batch of training faces goes forward through the network
  • the network gives a score for each mood
  • the scores are compared with the correct moods to work out the loss
  • the error is passed backwards through the network (back propagation)
  • this finds the gradient for every weight
  • each weight is changed a little to reduce the loss, by an amount set by the learning rate (and, for Adam, its own step size)

2 Cross-entropy uses −log of the chance given to the right answer. A confident wrong guess gives the right answer a tiny chance, and −log of a tiny number is large. A large loss means large gradients, so training corrects those mistakes most strongly.
