A Tiny Mood Machine

MoodNet has 3,072 inputs, two hidden layers and 10 outputs. This network has the same parts, just far fewer of them: 2 inputs, 2 hidden neurons with ReLU, and 1 output.

Part Values
Inputs x1 = 1, x2 = 2
Weights into hidden neuron 1 W11 = 0.5, W12 = 0.25
Weights into hidden neuron 2 W21 = −0.5, W22 = 0.5
Weights into the output v1 = 1, v2 = 2
Right answer (target) 3
Loss (output − target)²

There are no biases, to keep the sums short. The numbers are chosen so you can work everything out in your head.

Work it out

Work out the forward pass, one step at a time, using the same three steps as every neuron in Session 3:

  1. z1 = W11 × x1 + W12 × x2, and h1 = ReLU(z1)
  2. z2 = W21 × x1 + W22 × x2, and h2 = ReLU(z2)
  3. output = v1 × h1 + v2 × h2
  4. loss = (output − 3)²

Then run the first two cells of your notebook to check.

Check

z1 = 0.5 + 0.5 = 1, so h1 = 1. z2 = −0.5 + 1 = 0.5, so h2 = 0.5. Output = 1 + 1 = 2. Loss = (2 − 3)² = 1. The output is too small.

Working Backwards

Back propagation answers one question for every weight: if I nudge this weight up a little, how much does the loss change? That number is the weight's gradient.

The loss depends on the output. The output depends on the hidden neurons. The hidden neurons depend on the weights. So you start at the loss and work backwards, one link at a time, multiplying as you go. This is called the chain rule.

Think of a row of gears. Turn the first gear and each gear turns the next. If gear A turns gear B twice as fast, and B turns C three times as fast, then A turns C six times as fast. Each link in the network is a gear, and the gradient is how fast the loss turns when you turn one weight.

These are the only rules you need:

To go from... ...multiply by
loss to output 2 × (output − target)
output to an output weight (v) the value that weight multiplied (h)
output to a hidden neuron (h) the weight on its connection (v)
through ReLU 1 if z was positive, 0 if it was negative
hidden neuron to an input weight (W) the input that weight multiplied (x)

The Backward Pass

Work it out

Work out each gradient, in this order, using the table above. Type each answer into the YOUR TURN cell as you go.

  1. loss to output
  2. the two output weights, v1 and v2
  3. the two hidden neurons, h1 and h2

In your notebook

Run your YOUR TURN cell. Then run the next cell. loss.backward() should give exactly the same numbers:

PyTorch gradients for v: [-2.0, -1.0]
PyTorch gradients for W: [[-2.0, -4.0], [-4.0, -8.0]]

Think

  1. Every gradient is negative. Which way will each weight move?
  2. W22's gradient (−8) is the biggest. Why does that weight matter most?
Answers
  1. The update takes away learning rate × gradient, so every weight goes up. That makes sense: the output (2) is below the target (3), and every weight here pushes the output up.
  2. It's on the path with the biggest numbers: its input is x2 = 2, and the next weight along is v2 = 2.

Update and Check

Each weight now takes a step: new weight = old weight − learning rate × gradient. With a learning rate of 0.01, v1 = 1 − 0.01 × (−2) = 1.02.

In your notebook

Run section 3. With a learning rate of 0.01, one step brings the loss down from 1 to 0.22. Then do the YOUR TURN cell with a learning rate of 0.05.

What happens with 0.05?

The loss goes up, to 2.98. The step is so big that the output jumps from 2 to about 4.7: further past the target than it started below it. It's the same overshoot as the bounce line with a learning rate of 0.8.

In your notebook

Run section 4. It builds the same shape of network with PyTorch layers, like MoodNet, and prints every gradient. Look for a hidden neuron whose gradients are all 0.

Why are some gradients 0?

One of the hidden neurons has a negative total, so ReLU outputs 0 and its slope is 0. Nothing passes back through it, so none of its weights change for this input. If a neuron's total is negative for every input, it never learns again. This is called a dead neuron.

Check Your Understanding

Check your understanding

1. The Mood Machine guesses a mood that is wrong. Describe how back propagation is used to improve it. 4 points

2. Explain what the learning rate does when weights are updated. 2 points

What a full answer includes

1 Any 4 of:

  • the output is compared with the right answer to work out the loss (error)
  • the error is passed backwards through the network, from the output layer towards the input layer
  • the chain rule is used to find how much each weight added to the error (its gradient)
  • each weight is changed in the direction that reduces the error
  • by an amount set by its gradient and the learning rate
  • this is repeated for many faces and many epochs until the error is small

2 It sets how big each change to the weights is. Too big and the changes overshoot, so the error can go up. Too small and learning is very slow.
