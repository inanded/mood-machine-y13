Key terms for topic 18.1

Glossary

The words you need for this unit, in the order you meet them.

Term Meaning
Artificial intelligence (AI) A system that does a task we would call intelligent if a person did it.
Machine learning (ML) AI that improves at a task by learning from data instead of following hand-written rules.
Deep learning Machine learning using artificial neural networks with many hidden layers.
Supervised learning Learning from labelled data, where each example comes with the right answer.
Classification Supervised learning that predicts a category, such as a mood.
Regression Supervised learning that predicts a number, such as a bounce height.
Unsupervised learning Learning from unlabelled data by finding structure, such as clusters.
Reinforcement learning An agent learns a policy by taking actions in an environment and receiving rewards or penalties.
Agent, environment, reward, policy In reinforcement learning: the learner, the world it acts in, the feedback score, and its strategy for choosing actions.
Artificial neural network Layers of connected nodes (neurons): an input layer, one or more hidden layers and an output layer.
Neuron / node Multiplies each input by a weight, adds them and a bias, then applies an activation function.
Weight The number on a connection that scales an input. Learned during training.
Bias A number that belongs to a neuron, added to its weighted inputs before the activation function. It sets how easily the neuron switches on. Learned during training.
Activation function A function applied to a neuron's total, such as ReLU. It lets networks model relationships that are not straight lines.
ReLU Rectified linear unit: outputs the total if it is positive, otherwise 0. The bend at 0 is what lets a network learn patterns that aren't straight lines.
Tensor A grid of numbers with any number of dimensions.
Seed The starting number for a random number generator. The same seed always gives the same "random" numbers, so results can be repeated.
Dataset A numbered collection of examples, each a pair of input and right answer.
Forward pass Sending inputs through the network, layer by layer, to get its output.
Loss function A single number measuring how wrong the model's outputs are.
Mean squared error (MSE) The mean of the squared differences between predictions and actual values.
Softmax Turns a list of scores into chances that are all positive and add up to 1.
Cross-entropy loss The loss used for classification: −log of the chance given to the right class. Close to 0 when the model is sure and right, large when it is sure and wrong.
Gradient How much the loss changes when a parameter changes, and in which direction.
Gradient descent Repeatedly moving each parameter a small step against its gradient to reduce the loss.
Learning rate The size of each gradient descent step.
Optimiser The code that changes the weights using their gradients, such as plain gradient descent (SGD) or Adam.
Adam An optimiser that builds up speed in directions the gradients keep pointing, and gives every weight its own step size.
Back propagation Working backwards from the loss through the network with the chain rule to find the gradient for every weight, so the weights can be adjusted to reduce the error.
Chain rule The rule for differentiating a function of a function: multiply the rates of change along the path.
Epoch One complete pass through the training data.
Batch A group of examples processed together in one training step.
Training set / test set Data the model learns from / data held back to check it works on examples it has not seen.
Overfitting Fitting the training data so closely that performance on new data gets worse.
Confusion matrix A table of real classes against predicted classes, showing which mistakes a model makes.
Extrapolation Predicting for inputs outside the range of the training data.
