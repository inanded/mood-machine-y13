# The Mood Machine (Year 13)

An interactive site for teaching neural networks with PyTorch, built around the Mood Machine: an AI that reads the mood of cartoon emoji faces. Eleven 60-minute sessions for Cambridge International AS & A Level Computer Science 9618, Topic 18.1.

Each session page has short section videos, a starter Jupyter notebook and check-your-understanding questions. Open `index.html`, or visit the GitHub Pages site.

Worked teacher notebooks are kept separately and are not in this repository.
