Flatten: From Picture to List

A face is a (3, 32, 32) tensor: three grids. The neurons in a Linear layer expect one long list of inputs. Flatten unrolls the grids into a single row of 3 x 32 x 32 = 3,072 numbers: all of the red grid, then all of the green, then all of the blue.

For a batch, it unrolls each face separately: (64, 3, 32, 32) becomes (64, 3072).

In your notebook

Run section 1 to see the shapes before and after.

Think

After Flatten, two pixels that were next to each other, one above the other, end up 32 places apart in the list. Does MoodNet know they were neighbours?

Answer

No. To MoodNet, input 100 and input 132 are just two inputs. It has to learn from the data which positions matter together. That's one reason it struggles with faces that are moved or tilted, which you'll test in Session 10.

The Layers

class MoodNet(nn.Module):
    def __init__(self, hidden=256):
        super().__init__()
        self.flatten = nn.Flatten()
        self.hidden1 = nn.Linear(3 * 32 * 32, hidden)
        self.hidden2 = nn.Linear(hidden, 128)
        self.output = nn.Linear(128, 10)
        self.relu = nn.ReLU()

    def forward(self, x):
        x = self.flatten(x)
        x = self.relu(self.hidden1(x))
        x = self.relu(self.hidden2(x))
        return self.output(x)

The class has two parts:

  • __init__ builds the layers once, with random starting weights.
  • forward says what happens to a batch of faces as it passes through. Sending data through like this is called a forward pass.

Following one face through forward:

Step Layer Numbers out
1 Flatten 3,072
2 hidden1: 256 neurons, each reading all 3,072 inputs, then ReLU 256
3 hidden2: 128 neurons, each reading all 256, then ReLU 128
4 output: 10 neurons, each reading all 128 10 scores

There's no ReLU after the output layer: the scores can be any size, positive or negative. Two hidden layers make MoodNet a small deep network.

torch.manual_seed(1) before building it sets the seed for the random starting weights, so everyone in the class starts from the same MoodNet.

Counting the Numbers to Learn

Each Linear layer has one weight for every connection (inputs x neurons) and one bias for every neuron.

hidden2 256 x 128 = 32,768 128 32,896
output 128 x 10 = 1,280 10 1,290
MoodNet 820,874

96% of them are in the first layer, because every one of the 3,072 inputs connects to every one of its 256 neurons.

Scores, Chances and a Guess

MoodNet's output is 10 scores, one per mood. The biggest score is the guess.

Scores are hard to compare, so we turn them into chances with a function called softmax. Softmax makes every score positive and scales them so they add up to 1 (100%). A bigger score always gets a bigger chance.

Happy Sad ... Neutral
Score 2.0 0.5 ... 0.0
Chance 44% 10% ... 6%

In Session 8 you'll see that the loss is worked out from these chances.

Before Training

In your notebook

Run section 4 to mark the untrained MoodNet on all 3,000 test faces.

Think

  1. The ten chances are all close to 10%. Why?
  2. The accuracy is about 10%. Why that number?
Answers
  1. The weights start as small random numbers, so every score is small and none stands out. Softmax of ten nearly equal scores gives ten nearly equal chances.
  2. MoodNet is guessing. With ten moods, each equally common, a guess is right about one time in ten. Next session, training changes that.
